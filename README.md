## 📌 项目简介

CS2-XiaoPan 是一个围绕 CS2 客户端数据读取与可视化展示的学习型项目，主要包含：

- **ESP / 透视**：读取游戏内实体信息并进行屏幕绘制；
- **自瞄（Aimbot）**：基于骨骼/坐标数据的瞄准辅助逻辑；
- **投掷物助手**：地图投掷点位与轨迹提示；
- **扳机（Triggerbot）**：准星命中判定触发；
- **网页雷达**：通过本地 Web 页面展示雷达与玩家位置。

项目结构分为 C++ 模块（`Dll1.sln`）、Python 脚本（`Esp.py`）、配置目录（`XiaoPanSetting/`）以及 Web 雷达（`web/`）。

> 本项目不提供任何规避反作弊的方法，也不保证在任何环境下可用。请仅在自己的离线环境/研究环境中学习。

## ✨ 功能特性

| 模块 | 说明 | 相关文件 |
| --- | --- | --- |
| ESP 透视 | 玩家、骨骼、血量、距离等信息绘制 | `Esp.py`、`XiaoPanSetting/espsetting.json`、`bonessetting.json` |
| 自瞄 | 瞄准逻辑与平滑参数配置 | `XiaoPanSetting/` 下相关 json |
| 投掷物助手 | 地图投掷点位、轨迹参考 | `maps/`、`web/map/` |
| 扳机 | 命中触发逻辑 | `XiaoPanSetting/recoil.json` 等 |
| 网页雷达 | 浏览器端雷达图与玩家位置展示 | `web/index.html`、`web/js/radar.js`、`web/map/` |
| 地图资源 | 各地图雷达图与 meta 信息 | `maps/`、`web/map/` |
